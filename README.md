## Hosting setup (pending)
Connect this repository to Cloudflare Pages. Publish the repository root; no build command is needed for these static HTML pages. Configure syncrastore.io as a custom domain using the records returned by the hosting provider.

Updates to the production branch will publish automatically only after hosting is connected.

Do not commit passwords, API tokens or private files.
